# Construction Expense Tracker 🏗️

A web application designed to simplify the organization and management of construction-related expenses.

🔗 **Live Demo:** [Construction Expense Tracker](https://construction-expense-tracker-coral.vercel.app/)

## 📌 About the Project

The Construction Expense Tracker is a web-based project that provides a simple interface for managing construction expenses. It allows users to add, edit, and delete expense entries, helping organize expense information in one place.

This project is part of my journey in software development, with a focus on building practical web applications and exploring cloud backend integration.

## ✨ Features

- ➕ Add construction expense entries
- ✏️ Edit existing expenses
- 🗑️ Delete expense entries
- 🖥️ Simple and user-friendly interface
- ☁️ Supabase integration

## 🛠️ Tech Stack

- **Framework:** Next.js
- **Language:** JavaScript
- **Backend Service:** Supabase
- **Deployment:** Vercel

## 🚀 Getting Started

### Prerequisites

- Node.js and npm installed

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Vaishnavi-0506-kakollu/Construction-Expense-Tracker.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Construction-Expense-Tracker
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Configure the required environment variables for Supabase, if applicable.

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open [http://localhost:3000](http://localhost:3000) in your browser.
